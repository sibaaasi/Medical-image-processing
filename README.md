# Image Processing and Machine Learning in Python

Implementations exploring image processing, segmentation, object detection, and introductory machine learning.

## Projects

1. [Image transformations, edge detection, and coin detection](README-image-basics.md)
2. [Object counting and brain-image segmentation](README-segmentation.md)

3. [Handwritten-digit classification using KNN](README-knn.md)
4. [Training a sigmoid neuron from scratch](README-neuron.md)

## Input Images

The original input images are not included in this repository. The image-processing notebooks require images supplied by the user. The expected filenames and descriptions are listed in each project's README.

Results may differ when using alternative images. Some processing parameters were selected for the original examples and may need adjustment.

## Tools

Python, NumPy, OpenCV, Matplotlib, Pillow, and TensorFlow/Keras for loading MNIST.

## Running the Notebooks

The notebooks can be opened in Google Colab.

For image-based examples, upload the corresponding input images to the Colab runtime before running the cells. The segmentation notebooks include an upload prompt.

Run the cells in order.
